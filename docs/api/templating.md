# Interpolation

What `Loader(interpolate=...)` renders with: a tplx engine through
`TemplateInterpolator`, `${a.b}` references through `VarsInterpolator`, or an
object of your own with the `Interpolator` shape. See
[Templating](../guide/templating.md) for interpolation and template files.
